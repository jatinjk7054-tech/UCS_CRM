# UCS CRM — What Each Panel Does

A plain-language guide to every screen in the system. For each panel: what it is for, what its menu contains, and what each menu item does.

**How to read this:** Every panel is a separate section. Under each one you'll find the list of menu items exactly as they appear on the left side of the screen, followed by a one-line explanation of each.

---

## Which panel do I want?

| Panel | What it's for | Who can open it |
|---|---|---|
| Super Admin | Oversees everything across all organisations | Super Admin |
| HR | Manages volunteers, attendance, leave, salary | HR, Super Admin |
| NGO Admin | Runs one organisation — stations, field officers, targets | NGO Admin, Super Admin |
| Accounts | Money side — donors, receipts, certificates | Accounts, Super Admin |
| FRO | Day-to-day field work — calling donors, logging leads | Field Officer, Super Admin |
| Event Head | Plans events, activities and reports | Event Head, Super Admin |
| Recruiter | Finds and tracks candidates and interviews | Recruiter, Super Admin |
| SIM Card | Tracks SIM cards bought, assigned and expiring | Anyone signed in |
| Documentation | Built-in help and how-to guides | Anyone signed in |
| WhatsApp | Chats with donors over WhatsApp | Anyone signed in |
| Dev Panel | Technical issue tracker — used by the development team | Developer, Super Admin |
| Beneficiaries | People who receive kits, and the OTPs used to collect them | Inside Accounts |
| Library | Membership applications and coupons | Inside Accounts or HR |
| Metropad | Machine/metro equipment management | Inside Accounts |

## Super Admin

**What it's for:** The top-level view. One place to see how every organisation is doing, approve things, and jump into any other panel.

### Menu items

- **Dashboard** :: The main screen. Big number cards showing totals across the organisation, plus any items waiting for your approval.
- **Data Management** :: Uploads spreadsheets of donor data. You can inspect a file before importing it, see what has already been imported, and copy data down to individual organisations.
- **Organization** :: Adds and edits organisations and the causes they work for.
- **Volunteers** :: The full list of volunteers across every organisation. Search and filter them, view one person's profile, reset their password, or remove them.
- **Leaves** :: Leave requests sent by volunteers. You approve or reject each one.
- **Tickets** :: Requests from volunteers to correct their attendance. You check and approve or reject them.
- **Attendance** :: The attendance register for everyone, protected by a PIN. Add, change or delete attendance records and see any one person's month at a time.
- **Live FRO Status** :: A live board showing which field officers are online right now. Can pause or resume someone's availability, and run a meeting mode.
- **FRO Idle Report** :: Shows how long each field officer has been inactive. Lets you drill down into one person's daily log.
- **Assets Overview** :: Every asset the company owns, grouped by type and condition.
- **Incentives** :: Sets up and awards incentive campaigns. Includes a separate section for lead incentives.
- **Notices** :: Sends announcements to users. You choose whether it appears as a popup and which panels receive it.
- **Late Policy** :: Sets how many minutes late count as a half-day or a full-day deduction, per person.
- **Admin, Accounts, HR, FRO, Recruiter, Event Head** :: Shortcuts that open those other panels, so you don't have to navigate away and log in again.

### Grouped together

**Organization** and **Volunteers** are tucked under one heading to keep the menu short. Same screens as listed above.

## HR

**What it's for:** Everything about the people who work here — joining, daily attendance, leave, salary, and paperwork.

### Menu items

- **Overview** :: Your team at a glance. Head-count per department, who's in today, who's on leave, upcoming holidays and birthdays.
- **Volunteers** :: Add and manage volunteers. Search the list, export it, and remove someone who has left.
- **Attendance** :: Mark who is present today, and see any one person's full month. Exports to Excel.
- **Leaves** :: Leave requests. Approve or reject.
- **Letters** :: Generates official letters from templates — appointment, confirmation, and similar. You can print them or send them on WhatsApp.
- **HR Forms** :: The joining forms volunteers fill in, with printable versions and space for a signature.
- **Recruiters** :: The hiring pipeline: who applied, who has an interview booked, and where each candidate stands.
- **Reports** :: A daily HR summary covering recruiter numbers and attendance. Save it and share it on WhatsApp.
- **Quizzes** :: Looks up candidate quiz results that were marked automatically.
- **Holidays** :: A calendar showing holidays, events and birthdays. Add and remove entries.
- **QR Codes** :: Generates QR codes for geofenced attendance scanning. Print them and delete old ones.
- **Loans & Advances** :: Tracks loans given to volunteers, who has approved them, and how they'll be recovered from salary.
- **NGO & Salary** :: Pays and reports salary per organisation. Shows who belongs where, what each person earns, and what's already been paid.
- **FRO Targets** :: Sets the monthly collection target for each field officer.
- **Tickets** :: Attendance correction requests waiting for a decision.
- **Community** :: Team announcements. Read-only.
- **Library** :: Membership applications and coupons (see the Library panel below).

## NGO Admin

**What it's for:** Running one organisation day to day — your field officers, the stations they cover, and whether they're hitting their targets.

### Menu items

- **Dashboard** :: The main screen. Collection totals station by station, which officers are active, and how the telecallers are performing.
- **Stations & FROs** :: Manage stations and which officer covers which one. Rename stations in bulk, transfer donors between officers, and set monthly targets.
- **Attendance** :: Field officer attendance, with a breakdown for each person.
- **Agents** :: Staff who can log in and work one officer's data without holding that officer's own login. Create them, assign them, reset passwords, and switch them off.
- **Acting FRO Codes** :: When an officer is unavailable, generates a short-lived code so someone else can act as them. Shows which codes are active, used, or expired.
- **Tickets** :: Technical problems raised by your team.
- **Community** :: Team announcements.

There is also a **search** box at the top. It's not in the menu — it searches across donors, volunteers and stations at once.

## Accounts

**What it's for:** The money side. Who donates, how much, receipts, certificates, and payment reminders.

The menu is grouped so it stays readable. Click a group name to open it.

### Main

- **Lead and Audit** :: Checks that donations received actually match bank records, and flags any that don't.
- **Receipts** :: Creates receipts for donations. You can import a spreadsheet of donations, generate PDFs, and send receipts on WhatsApp.
- **Attendance** :: Today's attendance and each volunteer's monthly sheet, including their punch-in and punch-out selfie photos.

*Workforce* (group)
- **Salary & Advances** :: Salaries and loans for volunteers, on one screen with tabs.
- **Teams** :: Groups of volunteers, and the targets for each team.
- **Incentive** :: Sets the incentive amounts for each day of the week.
- **NGO wise Incentive** :: Incentive schemes run per organisation.

*Finance & Records* (group)
- **Asset Register** :: Everything the company owns — laptops, phones, equipment — who has it, its condition, and its warranty.
- **Donors** :: The donor list, which officer or station each donor belongs to, and full donor addresses.
- **Data** :: Donor data split into recently added and older records, with a tool to distribute and clean it up.

*Ceremony* (group)
- **Awards** :: Runs voting for award ceremonies, including a live results board.
- **Audience Voting** :: Lets people in the audience vote by scanning a QR code on their phone.
- **Certificates** :: Certificate templates. Fill one in and it generates the finished certificate, including bulk runs.

*Modules* (group)
- **Bill Reminder** :: Sends payment reminders and tracks who has paid.
- **Beneficiaries** :: People who received kits, and the collection OTPs (see below).
- **SIM Management** :: SIM cards (see below).
- **Library** :: Membership applications (see below).
- **Metropad** :: Machine and metro equipment management.

### Settings

- **Reports** :: Collection reports for a day, a month, or a custom date range, broken down by organisation, agent and team. Needs an access code.
- **Tickets** :: Open problems about payments, receipts and collections.
- **Community** :: Group chat with your team. Shows a badge when there are unread messages.

### Also available from the gear icon

- Razorpay account details
- Email account settings
- Sync and import settings
- Receipt template settings
- Change access code
- Change salary access code

## FRO (Field Officer)

**What it's for:** The daily working screen for someone collecting donations in the field.

### Menu items

- **Dashboard** :: Today at a glance: how many leads, who to follow up with, collection against target, and any notices.
- **My Leads** :: Your own donors and pending leads, side by side, with your performance across the top.
- **Donors** :: Your donor list, with each donor's history and receipts.
- **My Idle** :: How long your account has been sitting idle each day. Visible to you, not just your manager.
- **Lead Incentive** :: What you're on track for in the lead incentive scheme, and where you rank.
- **Raise Ticket** :: Report a problem and track the answer.
- **Community** :: Team chat.
- **Inbox** :: Not yet available. Shown greyed out.

## Event Head

**What it's for:** Planning events and activities, getting them approved, and reporting on them afterwards.

### Overview
- **Dashboard** :: How many events are planned, happening, and finished, plus any deadlines coming up.

### Programs
- **Events** :: The master list of all events. Change status, edit, or delete.
- **Calendar** :: A month, week or list view of everything scheduled, with a form to add new events.
- **Monthly Planner** :: Plans activities month by month for each organisation, with suggested programmes and festivals.
- **NGOs** :: Organisations taking part, with how many events each has.
- **Sectors** :: The types of work being done.
- **Activities** :: The activity list, with import and status controls.
- **Create Event** :: The form for adding a new event or activity.

### Planning & Manage
- **My Events** :: Just the events assigned to you.
- **Media / Banners** :: Photos and banners for events. Upload, preview, and choose the main banner.
- **Voluntary** :: The volunteers available to help, with import from HR.

### Reporting
- **Event Reports** :: Monthly reports per event or per organisation. Exports for sharing.
- **Approval Workflow** :: Sends events for approval and lets you approve or reject them.
- **Notifications** :: Deadlines coming up.
- **My Tickets** :: Problems you have raised.
- **All Tickets** :: Every technical problem, for the people responsible for fixing them.

### Community
- **Community** :: Team chat.

## Recruiter

**What it's for:** Finding candidates and keeping interviews moving.

### Menu items

- **Dashboard** :: How the hiring pipeline looks right now.
- **Leads** :: Everyone who has shown interest. Add, edit, move between stages, and filter.
- **Candidates** :: Search applicants, record their details, and schedule, complete or cancel interviews.
- **Tickets** :: Technical problems.

## SIM Card

**What it's for:** Keeping track of every SIM card — what's in stock, who has it, and which ones are about to expire.

### Menu items

- **Dashboard** :: Counts of active, expiring, expired and replaced SIMs.
- **All SIM Cards** :: The complete list. Change the status of several at once, or delete them.
- **SIM Inventory** :: Cards physically in stock, split into available, assigned, expired, lost and damaged.
- **Expiring SIMs** :: Cards close to expiring, with filters for the next 7 days, next 30 days, or already expired.
- **SIM Replacements** :: Start a replacement for a SIM that's about to expire.
- **Replacement History** :: A record of every replacement made.
- **SIM Reports** :: Analysis of expiries and stock, with export.
- **Import / Export** :: Bring in SIM cards from a spreadsheet, or export the list. A blank template is available to download.
- **Settings** :: Reminder preferences — how many days before expiry to warn, and the default team.

## Beneficiaries

Reached from **Accounts → Beneficiaries**. It has no menu of its own; instead each screen is a tab across the top.

- **Overview** :: How many beneficiaries there are, broken down by organisation, plus four reports.
- **All Beneficiaries** :: The full list, with filters, bulk delete and spreadsheet export.
- **Collection OTPs** :: The 6-digit codes given out when someone has already collected their kit but needs another. Used to verify a collection.
- **Import Members** :: Adds beneficiaries from a spreadsheet.
- **Daily Events** :: Distribution events and the people running them.
- **A person's profile** :: Clicking someone opens their full record, including family, education, employment and a history of what has been given.

---

## Library

Reached from **Accounts → Library** or **HR → Library**. No menu — three tabs.

- **Applications** :: Membership applications, searchable and filterable. Open one to approve, reject, or renew it, and to generate the member's ID document.
- **Coupons** :: Create coupons and email them to selected applicants.
- **Import members** :: Adds members from a spreadsheet.

---

## Metropad

Reached from **Accounts → Metropad**. A separate, small system for managing machines and metro equipment. It has a single menu item.

- **Dashboard** :: The equipment overview.

## WhatsApp

Reached from the WhatsApp link, with no menu of its own.

Shows the WhatsApp inbox: the list of conversations on the left, and the chosen conversation on the right. You can send photos, use message templates, and use quick replies.

**Note:** Inside the FRO panel, the Inbox item is greyed out — use this panel instead.

Reached from the help link. This is a built-in guide. The menu on the left lists what it covers.

- **Global Auth System** :: How sign-in works and who can see what.

## Dev Panel

**What it's for:** A technical issue tracker, used by the development team to record and follow up bugs and requests.

### Menu items

- **Dashboard** :: Open issues, how they are spread by status, and which ones need attention.
- **All Tickets** :: Every issue in the system. Filter, assign, and update several at once.
- **My Tickets** :: Only the issues assigned to you.
- **Unassigned** :: Issues nobody has picked up yet.
- **Community** :: Team chat.

## Menu items shared across panels

A few screens look the same wherever you find them:

- **Community** :: The same team chat appears in Super Admin, HR, NGO Admin, Accounts, FRO, Event Head, Recruiter and Dev Panel. It shows a small badge on the menu when there are unread messages.
- **Tickets** :: The technical problem tracker is shared, but each panel only shows its own team's problems and can only do what that team is allowed to do.

---

## Things worth knowing

- **Some menu items are hidden.** A few screens exist and work, but are deliberately left off the menu. They can still be reached by their address. This is on purpose, not a mistake.
- **Some screens change shape depending on where you are.** For example, the SIM Card section has one set of options on its own and a fuller set inside Accounts. Both show the same information.
- **Access is by role.** Your menu shows what your role allows. If something is missing, it may be there for a different role.
- **Passwords and access codes** are separate things. Some screens ask for an access code before they open.
